# Мои деньги

Простое персональное web-приложение для учёта доходов, расходов, месячных бюджетов и денег по счетам.

## Версия

**1.8.1**

## Основные возможности

- Доходы и расходы по категориям.
- Периоды, сравнение с предыдущим периодом и аналитика расходов.
- Месячный бюджет и лимиты по категориям.
- Счета/кошельки с текущими остатками.
- Стартовые счета: **Наличные**, **Банк 1**, **Банк 2**.
- Свои счета: добавление, переименование и начальный остаток.
- Привязка каждого дохода и расхода к счёту.
- Переводы между счетами без влияния на доходы и расходы.
- Фильтрация аналитики по конкретному счёту.
- **Необходимый минимум** — общий финансовый порог для суммы денег на всех счетах.
- Запас/дефицит относительно необходимого минимума и процент его покрытия.
- Быстрая кнопка **«+ Добавить расход»** в верхней части приложения.
- Supabase Auth и RLS — пользователь видит только свои данные.

## Обновление с v1.7.0 до v1.7.1

SQL-миграция **не требуется**. База данных и Supabase не меняются.

Сохраните свой `.env.local`, замените файлы проекта и выполните:

```powershell
npm.cmd install
npm.cmd run build
npm.cmd run dev
```

После проверки:

```powershell
git add .
git commit -m "Add quick expense button v1.7.1"
git push
```

## Environment variables

```env
VITE_SUPABASE_URL=...
VITE_SUPABASE_PUBLISHABLE_KEY=...
```

`.env.local` не нужно добавлять в Git.

## Авторизация v1.8.1

Используется Supabase Auth по email + паролю, как в проекте «Моя машина».

- Вход: `signInWithPassword({ email, password })`
- Регистрация: `signUp({ email, password })`
- Минимальная длина пароля в интерфейсе: 6 символов
- Для перехода со старого Magic Link существующий авторизованный пользователь может нажать «Пароль» в шапке и задать пароль через `updateUser({ password })`.

SQL-миграция для v1.8.1 не требуется.
