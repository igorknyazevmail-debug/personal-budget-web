# Мой бюджет v1.5.1

Простое личное web-приложение на React/Vite + Supabase для учёта расходов, доходов, категорий, статистики и месячных лимитов.

## Возможности

- расходы по категориям;
- доходы по отдельным категориям;
- редактирование и удаление операций;
- фильтры периода;
- статистика расходов по категориям и интерактивная диаграмма;
- отдельная динамика расходов относительно предыдущего периода;
- баланс периода: доходы − расходы;
- доля сбережений;
- явное изменение баланса относительно предыдущего периода;
- отдельная динамика доходов;
- общий месячный лимит и лимиты расходов по категориям;
- доходы и баланс выбранного месяца;
- Supabase Auth и RLS: каждый пользователь видит только свои данные.

## Обновление с v1.5.0

SQL-миграция не нужна. v1.5.1 меняет только интерфейс и расчёт отображаемой динамики.

Сохрани существующий `.env.local`, замени файлы проекта файлами из архива и запусти:

```powershell
npm.cmd install
npm.cmd run dev
```

Для проверки production-сборки:

```powershell
npm.cmd run build
```

## Переменные окружения

Создай `.env.local`:

```env
VITE_SUPABASE_URL=https://YOUR_PROJECT.supabase.co
VITE_SUPABASE_PUBLISHABLE_KEY=sb_publishable_...
```

Не используй `SUPABASE_SECRET_KEY` в браузерном приложении.

## База данных

Для нового проекта можно выполнить `supabase.sql` целиком.

Если база уже обновлена до v1.5.0, для v1.5.1 выполнять SQL не нужно.
