Мой бюджет v1.5.0 — обновление с v1.4.0

1. Сохрани существующий файл .env.local.
2. В Supabase открой SQL Editor -> New query.
3. Выполни целиком файл supabase-v1.5.0-migration.sql.
   Он добавляет только таблицы budget_incomes и budget_income_categories.
   Существующие расходы, категории и лимиты не изменяются.
4. Замени файлы проекта файлами из архива v1.5.0, сохранив свой .env.local.
5. Выполни:

   npm.cmd install
   npm.cmd run dev

6. Для дополнительной проверки:

   npm.cmd run build

Новое в v1.5.0:
- учёт доходов;
- отдельные категории доходов с добавлением, переименованием и удалением;
- редактирование и удаление доходов;
- баланс выбранного периода: доходы - расходы;
- доля сбережений: баланс / доходы;
- изменение баланса к предыдущему сопоставимому периоду;
- доходы и баланс месяца внутри блока месячного бюджета.
