Мои деньги v1.8.1

Изменения:
- В шапке оставлена только основная кнопка «+ Добавить расход».
- Редкие действия «Сменить пароль» и «Выйти» перенесены в компактное меню ⋮ справа.
- SQL-миграции не требуются.

Обновление:
1. Сохраните .env.local.
2. Замените файлы проекта файлами версии 1.8.1.
3. Выполните npm.cmd run build и npm.cmd run dev.
4. После проверки: git add . && git commit -m "Move account actions to menu v1.8.1" && git push
