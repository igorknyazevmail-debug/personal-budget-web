Мой бюджет v1.4.0

Что нового:
- Месячный бюджет с выбором месяца.
- Общий месячный лимит.
- Отдельные лимиты по категориям.
- Показатели «Потрачено / Общий лимит / Осталось».
- Прогресс использования общего лимита и лимитов категорий.
- Предупреждение с 80% лимита и индикация превышения с 100%.
- Лимиты хранятся отдельно для каждого месяца.

Обновление базы данных:
1. Откройте Supabase -> SQL Editor -> New query.
2. Выполните целиком файл supabase-v1.4.0-migration.sql.
3. Миграция добавляет только таблицы budget_monthly_settings и budget_category_limits.
4. budget_expenses, budget_categories и существующие данные не изменяются.

Обновление проекта:
1. Сохраните существующий .env.local.
2. Замените файлы проекта файлами версии 1.4.0.
3. Верните .env.local в корень проекта.
4. Выполните npm.cmd install (если нужно).
5. Выполните npm.cmd run dev.
