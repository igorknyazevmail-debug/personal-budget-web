Мой бюджет v1.5.1 — обновление с v1.5.0

SQL выполнять НЕ нужно.

1. Сохрани существующий файл .env.local.
2. Замени файлы проекта файлами из архива v1.5.1, сохранив свой .env.local.
3. Выполни:

   npm.cmd install
   npm.cmd run dev

4. Для дополнительной проверки:

   npm.cmd run build

Новое в v1.5.1:
- нижний блок сравнения переименован в «Динамика расходов»;
- в «Балансе периода» явно подписано «Изменение баланса к предыдущему периоду»;
- рядом добавлена отдельная «Динамика доходов» с текущей и предыдущей суммой;
- аналитические карточки стали компактнее;
- пять расходных показателей размещаются в одну строку на широком экране;
- адаптивная верстка сохранена для планшета и телефона.
