Мои деньги v1.7.1

Что нового:
- В верхней части приложения добавлена кнопка «+ Добавить расход».
- Кнопка плавно прокручивает страницу к форме добавления расхода.
- После прокрутки курсор автоматически устанавливается в поле суммы.
- Если в этот момент редактировался существующий расход, форма переключается в режим добавления нового расхода.

База данных и Supabase:
- Изменений нет.
- SQL-миграция не требуется.

Обновление:
1. Сохранить .env.local.
2. Заменить файлы проекта.
3. npm.cmd install
4. npm.cmd run build
5. npm.cmd run dev
6. После проверки: git add . && git commit -m "Add quick expense button v1.7.1" && git push
