Мои деньги v1.7.0

1. В Supabase SQL Editor выполните supabase-v1.7.0-migration.sql.
2. Сохраните существующий .env.local.
3. Замените файлы проекта файлами этой версии.
4. Выполните npm.cmd install и npm.cmd run build.
5. Запустите npm.cmd run dev.

Новое:
- Необходимый минимум для общей суммы на всех счетах.
- Запас/дефицит относительно минимума.
- Процент покрытия и индикатор прогресса.
- Минимум хранится в Supabase отдельно для каждого пользователя.
