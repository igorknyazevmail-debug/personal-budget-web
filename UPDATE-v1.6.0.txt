Мои деньги v1.6.0 — счета и переводы

Что нового:
- Счета/кошельки: Наличные, Банк 1, Банк 2 и любые собственные счета.
- Для каждого счёта показывается текущий остаток.
- Можно задать начальный остаток, переименовать счёт и добавить новый.
- Расходы и доходы теперь привязаны к конкретному счёту.
- Добавлен общий фильтр по счёту.
- Добавлены переводы между счетами. Перевод не считается доходом или расходом.
- В списках доходов/расходов отображается используемый счёт.
- Все старые операции после миграции автоматически относятся к счёту «Наличные».

Обновление:
1. В Supabase SQL Editor выполнить целиком файл supabase-v1.6.0-migration.sql.
2. Сохранить свой .env.local.
3. Заменить файлы проекта файлами версии 1.6.0.
4. npm.cmd install
5. npm.cmd run build
6. npm.cmd run dev
7. После проверки: git add . && git commit -m "Add accounts and transfers v1.6.0" && git push

SQL-миграция не удаляет существующие доходы, расходы, категории или лимиты.
