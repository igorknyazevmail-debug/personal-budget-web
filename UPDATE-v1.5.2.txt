Мои деньги v1.5.2 — обновление с v1.5.1

Что изменено:
- приложение переименовано с «Мой бюджет» в «Мои деньги»;
- новое название отображается на экране входа и в основном интерфейсе;
- заголовок вкладки браузера изменён на «Мои деньги»;
- версия обновлена до 1.5.2.

База данных и Supabase не меняются.
SQL выполнять не нужно.

Обновление:
1. Сохрани существующий .env.local.
2. Замени файлы проекта файлами v1.5.2.
3. Выполни npm.cmd install (при необходимости).
4. Выполни npm.cmd run dev для локальной проверки.
5. Выполни git add . && git commit -m "Rename app to Мои деньги v1.5.2" && git push.
6. Vercel автоматически создаст новый deployment из ветки main.

GitHub-репозиторий и Vercel-домен personal-budget-web можно не переименовывать — это не влияет на название приложения.
