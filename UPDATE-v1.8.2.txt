Мои деньги v1.8.2

Изменения:
- добавлена иконка приложения для вкладки браузера;
- добавлены favicon.png, favicon.ico и apple-touch-icon.png в public/;
- заголовок вкладки остается «Мои деньги».

SQL-миграция не требуется.

Обновление:
1. Сохраните свой .env.local.
2. Замените файлы проекта файлами версии 1.8.2.
3. npm.cmd run build
4. npm.cmd run dev
5. После проверки: git add . && git commit -m "Add app favicon v1.8.2" && git push
