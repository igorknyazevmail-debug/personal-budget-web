Мои деньги — обновление v1.8.0

Что изменилось:
- Magic Link заменён на вход по email + паролю.
- Добавлены режимы «Войти» и «Зарегистрироваться».
- Пароль — минимум 6 символов.
- Для существующего аккаунта, который раньше использовал Magic Link, в шапке приложения появилась кнопка «Пароль».
  Пока вы ещё авторизованы старой сессией, нажмите её и задайте пароль. После этого можно выходить и входить обычным способом.
- SQL-миграция не требуется.

После замены файлов:
npm.cmd install
npm.cmd run build
npm.cmd run dev

После проверки:
git add .
git commit -m "Switch to password auth v1.8.0"
git push
